# Smart-Grid
Es un simulador de red eléctrica en C++ basado en un grafo dirigido construido con una multilista de punteros. Su objetivo es calcular rutas óptimas para minimizar pérdidas de energía mediante algoritmos (Dijkstra, BFS, DFS) y gestionar clientes que ganan recompensas ("Eco-Tokens"), guardando toda la información en archivos JSON
